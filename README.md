# Windows 10 Web Edition

Интерактивная эмуляция рабочего стола Windows 10 прямо в браузере. Проект написан
на **React 18 + TypeScript + Vite + Tailwind CSS + Lucide React**, без единой
сторонней библиотеки для drag-and-drop и управления окнами.

![Стек](https://img.shields.io/badge/React-18-61DAFB) ![Стек](https://img.shields.io/badge/TypeScript-5-3178C6) ![Стек](https://img.shields.io/badge/Vite-5-646CFF) ![Стек](https://img.shields.io/badge/Tailwind-3-38B2AC)

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173 (сервер слушает 0.0.0.0)
npm run build    # tsc --noEmit + production-сборка в dist/
npm run preview  # предпросмотр production-сборки
npm run typecheck
```

## GitHub Pages

Сайт опубликован по адресу:

**https://s4rgeant1k.github.io/Windows-Web-Edition/**

Деплой автоматический: workflow `.github/workflows/deploy-pages.yml` при push
в `main` (или в ветку проекта) собирает приложение командой
`npm run build -- --base /Windows-Web-Edition/`, добавляет `404.html` для SPA
и публикует артефакт через `actions/upload-pages-artifact` + `actions/deploy-pages`.
Все URL ассетов строятся через `src/lib/assets.ts` на основе
`import.meta.env.BASE_URL`, поэтому иконки и обои корректно работают и локально
(`/`), и на подпути Pages.

**Особенность этого репозитория:** Pages изначально включён в legacy-режиме
(источник — ветка `main`, корень), а токен интеграции не имеет прав менять
`build_type` (API возвращает 403). Поэтому workflow сначала пытается переключить
источник на **GitHub Actions**, а если не получается — дожидается завершения
legacy Jekyll-сборки и публикует собранный артефакт **после** неё (иначе Jekyll
перезапишет сайт исходниками). Рекомендуется один раз переключить источник
вручную: **Settings → Pages → Build and deployment → Source: GitHub Actions** —
после этого workflow работает по стандартной схеме без ожидания.
Ручной запуск — кнопка **Run workflow** во вкладке Actions репозитория.

## Что реализовано

### Подсистема окон (`src/components/WindowManager`)
- Перетаскивание за заголовок на чистых событиях указателя
  (`onPointerDown` / `onPointerMove` / `onPointerUp` + pointer capture).
- 8 зон изменения размера (4 ребра + 4 угла), свободное растягивание и
  сохранение пропорций при зажатом **Shift** на углах.
- Ограничение координат и размеров рабочей областью экрана (минус 48 px панели задач).
- Двойной клик по заголовку, кнопки свернуть / развернуть / закрыть; развёрнутое
  окно занимает `100vw × (100vh − 48px)` и может быть «оторвано» перетаскиванием.
- Во время движения окна геометрия пишется напрямую в DOM, а в стор сохраняется
  один раз по `pointerup` — 60 FPS без 60 ререндеров React.

### Глобальное состояние (`src/context/OSContext.tsx`)
- React Context + внешний стор и `useSyncExternalStore` с селекторами:
  компоненты перерисовываются только при изменении своего среза.
- `windows[]` с уникальным ID, заголовком, `appId`, геометрией, флагами
  `isMaximized` / `isMinimized`, `zIndex` и `restoreBounds`.
- `activeWindowId` — фокус поднимает `zIndex` окна над остальными.
- `fileSystem` — древовидный диск `C:` (`C:/Users/Desktop`, `C:/Documents`,
  `C:/Users/Downloads`, `C:/Users/Pictures`, `C:/$Recycle.Bin`) с сохранением
  в `localStorage` (debounce 180 мс); настройки темы, цвета, обоев и звука тоже персистентны.
- Все операции с файлами иммутабельные: создать, переименовать, записать,
  удалить в Корзину, восстановить, очистить Корзину, сбросить диск.

### Рабочий стол и оболочка
- Обои в стиле Windows 10 (оригинальное изображение + 2 SVG-варианта),
  сетка иконок вдоль левого края, ярлыки и файлы `.txt` с рабочего стола.
- Контекстное меню правой кнопкой мыши: **Обновить**, **Сменить обои**,
  **Создать текстовый документ**, **Создать папку**, **Персонализация**;
  у объектов — открыть, переименовать, удалить, свойства.
- Панель задач: `bg-[#101010]/85 + backdrop-blur-md`, логотип «Пуск»,
  рабочий поиск по программам и содержимому файлов, представление задач,
  кнопки запущенных окон с подчёркиванием активного, системный трей
  (сеть, громкость, часы ЧЧ:ММ:СС) и центр уведомлений с быстрыми действиями.
- Меню «Пуск»: плавное появление снизу, левая полоса (профиль, настройки,
  питание: сон / перезагрузка / выключение), алфавитный список программ
  и интерактивные «живые плитки» с реальными данными (время, дата, число файлов).

### Приложения
| Приложение | Возможности |
| --- | --- |
| **Проводник** | Навигация вперёд/назад/вверх, адресная строка, быстрый доступ, двойной клик по `.txt` открывает Блокнот, создание/переименование/удаление, Корзина с восстановлением |
| **Блокнот** | `<textarea>` на всё окно, автосохранение в `fileSystem`, меню Файл/Правка/Вид, `Ctrl+S`, `Ctrl+N`, `F5` (вставка даты), масштаб, перенос слов, строка состояния |
| **Настройки** | Светлая/тёмная тема, 8 акцентных цветов (по умолчанию `#0078D7`), выбор обоев, секунды в часах, громкость, сброс ФС и раздел «О системе» |
| **Браузер** | Адресная строка, история вперёд/назад, домашняя страница с закладками, `<iframe>` и честное предупреждение с кнопкой «В новой вкладке» на случай `X-Frame-Options` / CSP `frame-ancestors` |

### Горячие клавиши
`Win` — меню «Пуск» · `Alt+F4` — закрыть активное окно · `F5` — обновить рабочий стол /
вставить дату в Блокноте · `Ctrl+S` / `Ctrl+N` — Блокнот · `Delete` — удалить выбранный файл ·
`Escape` — снять выделение / закрыть меню · `Shift` при растягивании угла — сохранить пропорции.

## Заметки

- Данные хранятся в `localStorage` ключами `wwe.filesystem.v1` и
  `wwe.preferences.v1`. Чтобы вернуть исходное состояние — «Настройки →
  Система → Сбросить файловую систему».
- Сторонние сайты в `<iframe>` могут запрещать встраивание на своей стороне;
  это ограничение самого сайта, а не эмулятора — используйте кнопку
  «В новой вкладке» в предупреждении браузера.
- Обои и иконки в `public/assets` — оригинальные изображения в стиле Windows 10,
  созданные специально для этого проекта.
